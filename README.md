# Customer Churn / Propensity Model

![Python](https://img.shields.io/badge/Python-3.12-blue?logo=python&logoColor=white)
![scikit-learn](https://img.shields.io/badge/scikit--learn-LogReg%20%7C%20RandomForest-F7931E?logo=scikitlearn&logoColor=white)

Trains and rigorously validates two classifiers — Logistic Regression (an
interpretable "scorecard"-style model, directly analogous to credit
scoring practice) and Random Forest (a stronger, less interpretable
comparison) — to predict customer churn from account and engagement
features. This is the **supervised** counterpart to the unsupervised
segmentation project elsewhere in this portfolio: here the target is
known, and the model is validated against held-out ground truth with
standard classification metrics rather than descriptive clustering alone.

## Data note

Real customer/account data is confidential. This runs on a synthetic
dataset with **deliberately imperfect, noisy signal** — several candidate
features have no true relationship to churn at all, specifically to test
whether the model learns to correctly down-weight them. See
`results/findings.md` for what it actually learned.

## Key findings

- **AUC ~0.67** (Logistic Regression, cross-validated) — a real, modest,
  honestly-reported result, not an inflated number
- **The simpler model won**: Logistic Regression slightly outperformed
  Random Forest — reported as a genuine finding, not buried because it's
  the "less impressive" model
- **The model mostly, but not perfectly, learned to ignore noise
  features** — one pure-noise feature (credit score) still received a
  moderately-sized spurious coefficient, a realistic and important caveat
- **Despite the modest AUC, targeting the top 3 risk deciles (30% of
  customers) captures 45.9% of actual churners** — a real, substantial
  efficiency gain for a retention team

## Method

1. Synthetic data generation with genuine, but noisy, churn signal
2. Stratified train/test split (75/25) preserving churn rate in both sets
3. **Logistic Regression** (standardized features) — interpretable
   coefficients, directly comparable to a credit-scoring scorecard
4. **Random Forest** — comparison model
5. Evaluation: ROC-AUC, Precision-Recall/Average Precision, 5-fold
   cross-validation (not just a single train/test split), calibration
   curves and Brier score
6. **Decile and lift analysis** — the standard business-facing view in
   propensity modelling: how much value does risk-ranked targeting add
   over random targeting?
7. Feature importance / coefficient interpretation, checked against which
   features were and weren't part of the true data-generating process
8. Business threshold selection with an explicit discussion of the
   precision/recall trade-off

## Relevance to credit scoring

Swap the label from "churned" to "defaulted" or "responded to offer," and
this exact pipeline — scorecard-style interpretable model, black-box
comparison, ROC/calibration/decile evaluation, business threshold
discussion — applies directly to credit risk scoring or marketing
propensity modelling.
